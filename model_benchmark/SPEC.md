# Model Benchmark — зафиксированная спецификация

Отдельный подпроект TeachAI: сравнение LLM на типовых сценариях учителя, без клона всего TI.

## Цель

На фиксированных промптах TeachAI сравнить 4–5 моделей и сделать вывод:
какой компромисс **качество / цена / стабильность** лучше для проекта
(подтвердить текущий выбор OpenAI или честно указать альтернативу).

## Курс для MVP

- Курс: **Основы Python** (`python-basics`)
- Стиль общения: `friendly`
- Пользователь в промптах: `Студент`

## Критические сценарии (MVP)

| ID | Тип | Зачем |
|----|-----|--------|
| `lesson` | Генерация текста урока | Главный объект смысловой оценки судьями |
| `course_plan` | План курса (JSON) | Фильтр структуры + пригодность для парсера |
| `qa` | Ответ на вопрос студента | Релевантность и педагогичность |
| `examples` | Примеры кода | Автовалидация + качество кода |

На первый прогон приоритет: **5 тем уроков** + по 1–2 сценария остальных типов.

## Участники (модели под сравнением)

| Роль в проекте | Модель (GPTunnel id) |
|----------------|----------------------|
| Текущая базовая TI | `gpt-4o-mini` |
| Современная дешёвая OpenAI | `gpt-5.6-luna` |
| Современный баланс OpenAI | `gpt-5.6-terra` |
| Альтернатива A | `claude-5-sonnet` |
| Альтернатива B | `gemini-3.5-flash` |

Один и тот же промпт для всех участников (без подгонки под модель).  
Точные id сверены с `GET /v1/models` GPTunnel.

## Судьи (LLM-as-judge) — подтверждено

| Судья | Модель |
|-------|--------|
| J1 | `gpt-5.6-sol` |
| J2 | `claude-opus-5` |
| J3 | `gemini-3.1-pro` |

Правила судейства:
- тексты подаются как **Урок A/B/C…** без имён моделей-участников;
- оценка **только по рубрике** (`rubric.json`), шкала 0–2 по каждому критерию;
- итог по участнику = среднее баллов по судьям и по темам;
- участник может совпадать с судьёй по семейству — это нормально, поэтому судей **три из разных семейств**.

## Два слоя оценки

1. **Форма (автомат, отсев):** объём, наличие блоков/заголовков, для JSON — парсинг и схема; для кода — наличие ```python``` блоков.
2. **Смысл (судьи):** соответствие теме, полнота, объём/плотность, педагогичность, соответствие заданию.
3. **Стоимость и скорость:** `total_cost` из ответа GPTunnel (RUB) + latency; в leaderboard — `avg_gen_cost_rub`, `score_per_ruble`.

Сломанная форма → участник получает штраф / пометку `format_fail`, в смысловой рейтинг может не входить или входит с нулём по форме.

Накладные расходы судей (`sum_judge_cost_rub`) учитываются отдельно: это цена эксперимента, не цена урока в продакшене TeachAI.

## Шлюз API

- **GPTunnel** (`GPTUNNEL_API_KEY`) — `https://gptunnel.ru/v1`.
- Authorization: ключ **без** `Bearer`.
- Для тестового личного счёта: `useWalletBalance=true`.
- Результаты пишутся в `results/` (JSON), отчёт — ноутбук `Model_Benchmark.ipynb`.

## Что сознательно не делаем в MVP

- полный UI TeachAI;
- fine-tuning;
- ручная оценка всех текстов человеком (человек задаёт рубрику и читает итог).
