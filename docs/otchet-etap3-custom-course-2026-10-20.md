# Мини-отчёт: этап 3 — своё название курса

**Дата:** 2026-10-20  
**План:** `docs/razgovor-2026-10-19-kurator-dorabotki-plan-konspekt.md` (этап 3 / п.1 куратора)

---

## Что сделано

На экране выбора курса:

- «Курс из списка» — как раньше, dropdown из `courses.json`.
- «Своё название курса» — поле названия + необязательное описание → синтетический курс `id=custom_<slug>_<hex>`, `source=user` → тот же `generate_course_plan`. В `courses.json` **не** пишется.

Валидация: название 3–120 символов; описание до 2000. UI вынесен из раздутого `setup_interface.py`.

Заглушек нет.

---

## Как проверить

1. Restart kernel, GPTunnel, дойти до выбора курса.
2. Каталог: выбрать «Основы Python» → «Начать курс» — как раньше.
3. «Своё название»: например `Основы pandas для аналитика` → «Начать курс» → план и первый урок по этой теме.
4. Пустое/слишком короткое имя — предупреждение, без запроса к API.
