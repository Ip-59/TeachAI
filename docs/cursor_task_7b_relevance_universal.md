# Задание для Cursor: пакет 7b — универсальный разбор course vs outside

Один коммит, один пуш. Работай прямо в `main`. Тесты — в venv текущей машины
(`venv_W_L` на работе, `venv_H_L` дома). Секреты и ключи не трогать и не печатать.

## Зачем
Вопрос «что нового в питон 3.15» на уроке «Операторы и выражения» ошибочно
получил плашку «Вопрос вне курса» и причину про «тему текущего урока».
По правилам это `scope=course`: вопрос из предметной области курса, просто
не из этого урока. Нужен **универсальный** промпт (без списка «Python / данные / ML»
как единственной области), чтобы то же правило работало для любого курса.

## Шаг 2. relevance_checker.py — user-промпт (`_build_relevance_prompt`)
Заменить блок про `scope=course` / `scope=outside` / два «Не …».

Было:
```
scope=course — вопрос про Python, данные или машинное обучение,
для ответа на который нужна тема, которую этот урок не вводит
(другая тема курса или общий факт о языке вне занятия).
На такой вопрос отвечают. reason — одна фраза, что это не тема текущего урока.

scope=outside — вопрос вне курса.
Только здесь отказ. reason — одно-два предложения ученику о том,
что вопрос вне тем курса (Python, данные, машинное обучение).
Для scope=outside не пиши, что вопрос «не относится к теме урока»:
он не относится к курсу целиком.

Не пиши «не рассматривается в тексте», «отсутствует в материале».
Не ставь scope=course только потому, что вопрос «шире одной фразы» урока:
если ответ в основном опирается на материал этого урока — это scope=lesson.
```

Стало:
```
scope=course — вопрос из предметной области этого курса
(язык, инструменты, темы курса), но не из материала этого урока:
другая тема курса, общий факт о предмете курса, версии, новости
или возможности языка/инструментов курса вне текущего занятия.
На такой вопрос отвечают. reason — одна фраза, что это не тема текущего урока.

scope=outside — вопрос вне предмета курса целиком
(другая область: быт, спорт, погода и т.п.).
Только здесь отказ. reason — одно-два предложения ученику о том,
что вопрос вне предмета этого курса.
Для scope=outside запрещено писать про «тему урока», «текущий урок»
или «рамки урока»: вопрос не по курсу, а не «не по этому уроку».

Не пиши «не рассматривается в тексте», «отсутствует в материале».
Не ставь scope=course только потому, что вопрос «шире одной фразы» урока:
если ответ в основном опирается на материал этого урока — это scope=lesson.
Не ставь scope=outside только потому, что урок эту тему не вводит:
если вопрос всё ещё про предмет курса — это scope=course.
```

Остальной промпт (lesson, JSON-схема) не трогать.

## Шаг 3. tests/fake_llm.py
Правило распознавания relevance завязано на текст system. Заменить:
```
("relevance", r"scope=lesson, если вопрос", None),
```
на:
```
("relevance", r"scope=lesson — вопрос про материал этого урока", None),
```
Без этого сценарные тесты падают с «Неизвестный запрос к LLM».

## Шаг 4. tests/legacy_checks/relevance_prompt_checks.py
В `test_relevance_prompt_is_a_teacher_judgment` заменить блок assert'ов
после `"в тексте или коде"` на:
```
    assert "в тексте или коде" in lowered
    assert "предметной области этого курса" in lowered
    assert "понятия, операторы, синтаксис" not in lowered
    assert "3.15" not in lowered
    assert "= и ==" not in lowered
    assert "вне предмета этого курса" in lowered
    assert "запрещено писать про" in lowered
    assert "если вопрос всё ещё про предмет курса" in lowered
```
(старые assert про «которую этот урок не вводит» / «вне тем курса» /
«не относится к курсу целиком» убрать — этих фраз больше нет).
