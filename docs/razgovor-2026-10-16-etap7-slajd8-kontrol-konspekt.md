## Принятые решения

1. **Смысловой модерации ответов LLM почти нет** — это зафиксировано и отражено в речи.
2. **Контроль ответов модели** в докладе = формат/техника (JSON-поля плана, синтаксис примеров), не «процент точности» и не разбор смысла урока.
3. **Релевантность** в речи явно отделена: это контроль вопроса ученика, не качества сгенерированного урока.
4. **Оценивание** = тест по эталону и контрольное по выполнению кода (ответы ученика).
5. **JSON-план:** вложенность курс → `sections` → `topics` → `lessons`; ключи `id`, `title`, `description`, `duration_minutes` / `total_duration_minutes`, `keywords`; валидация достраивает каркас при отсутствии полей.
