4. Connection error при генерации учебного плана
================================================================================

Пользователь:
(Скриншот: ошибка «Не удалось сгенерировать учебный план: Connection error.»
Серая строка ERROR:setup_interface:... обрезалась.)

Причина:
При нажатии «Начать курс» система вызывает OpenAI API.
Connection error — не удалось достучаться до API (прокси, интернет,
недоступный прокси).

Исправления в коде:
1. Понятное сообщение вместо сырого Connection error
   (interface_utils.format_api_error).
2. Перенос длинного текста в цветных плашках (word-wrap, overflow-wrap).
3. Убран дублирующий ERROR: в интерфейсе (остаётся в debug-логе).
4. Три повторные попытки при генерации плана
   (make_api_request_with_retries в course_plan_generator.py).
5. Таймаут подключения 20 с в httpx.

Что проверить в .env (на тот момент):
OPENAI_API_KEY=sk-...
OPENAI_PROXY=http://логин:пароль@хост:порт

================================================================================
6. Явный переключатель режима: прокси или VPN/direct
================================================================================

Пользователь:
Надо сделать хотя бы на период отладки программы возможность указывать,
как работать: либо через прокси с OpenAI, либо с OpenAI без прокси, но
используя VPN, который включен в целом на систему. Как-то это возможно
сделать или нет?

Ответ: да, возможно. Добавлена переменная OPENAI_CONNECTION_MODE в .env.

Значения:
- direct — без прокси в коде; трафик через VPN/сеть на уровне ОС;
- proxy  — через HTTP-прокси из OPENAI_PROXY (или HTTPS_PROXY);
- auto   — proxy, если задан OPENAI_PROXY; иначе direct.

Альтернатива: OPENAI_USE_PROXY=true / false.

В режиме direct приложение игнорирует OPENAI_PROXY и системные HTTP_PROXY.

Примеры .env:

VPN (без прокси в приложении):
OPENAI_API_KEY=sk-...
OPENAI_CONNECTION_MODE=direct
LLM_MODEL=gpt-4o-mini

Через прокси:
OPENAI_API_KEY=sk-...
OPENAI_CONNECTION_MODE=proxy
OPENAI_PROXY=http://логин:пароль@хост:порт
LLM_MODEL=gpt-4o-mini

При старте в выводе:
🌐 OpenAI: прямое подключение (без прокси в приложении; VPN/сеть на уровне ОС)
или
🌐 OpenAI: через прокси (host:port)

Изменённые файлы:
- config.py — get_openai_connection_mode(), get_openai_proxy_url(),
  describe_openai_connection()
- content_utils.py — клиент OpenAI с учётом режима
- run_teachai.py — вывод режима при старте, config в порядке reload
- interface_utils.py — сообщения об ошибках
- setup_interface.py — форма знакомства, переход к уроку, обработка ошибок API
- course_plan_generator.py — повторные попытки запроса

8. Катастрофа с прокси — отключить всё, работать через VPN
================================================================================

Пользователь:
с прокси произошла какая-то катастрофа, удали или закомментируй все
настойки прокси, чтобы они пока не срабатывали ни в проекте, ни в самом
Cursor. Пока будем работать через запущенный ВПН.

Что сделано:

Проект TeachAI (.env и .env_прокси):
- OPENAI_CONNECTION_MODE=direct
- OPENAI_USE_PROXY=false
- все строки HTTP_PROXY, HTTPS_PROXY, OPENAI_PROXY закомментированы

config.py:
- режим auto больше НЕ включает прокси сам — только явный
  OPENAI_CONNECTION_MODE=proxy
- при direct из процесса Python удаляются переменные HTTP_PROXY,
  HTTPS_PROXY, OPENAI_PROXY, ALL_PROXY и т.п.
  (даже если они остались в shell)

run_teachai.py:
- при старте ноутбука тоже очищает прокси-переменные

.vscode/settings.json:
- http.proxySupport: off для терминала/расширений в этом проекте

Cursor (глобально, ~/.config/Cursor/User/settings.json):
- "http.proxy": ""
- "http.proxySupport": "off"
- "http.noProxy": ["*"]

Ярлык Cursor (/usr/share/applications/cursor.desktop) без прокси —
менять не пришлось.
В ~/.bashrc экспорты прокси уже были закомментированы.

Что сделать пользователю:
1. Полностью закрыть и снова открыть Cursor.
2. Kernel → Restart в ноутбуке.
3. Запустить TeachAI — в выводе должно быть:
   🌐 OpenAI: прямое подключение (без прокси в приложении; VPN/сеть на уровне ОС)

Когда понадобится вернуть прокси:
в .env поставить OPENAI_CONNECTION_MODE=proxy и раскомментировать
OPENAI_PROXY=...
