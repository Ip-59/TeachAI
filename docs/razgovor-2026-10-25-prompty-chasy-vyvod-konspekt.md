## Цель и итог

Урок «Настройка IDE» уехал в списки из-за механической вставки в промпт. Дальше чинили вывод, контрольные, понятия и отсечку вопросов. Параллельно выложили `doc/` и `docs/` на GitHub и убрали из актуального файла пароль прокси.

**Итог в коде:**

1. Промпт урока без ветки по словам `python` / `список` / `словарь`.
2. Если по уроку нет кода для редактора — справка, не красная «ошибка генерации».
3. Понятия составляются вместе с уроком. В профиль как пройденные — после теста >40 %, принудительного перехода или если ученик сам открыл список.
4. КЗ спрашивает модель, нужен ли код, с учётом того, что студент уже прошёл. Задание на переменную для урока про установку IDE не должно появляться.
5. Вопрос по курсу, но не по текущему уроку, получает ответ и пометку. Отказ только вне курса. Конкретных вопросов в коде нет.
6. Ответ на вопрос не режется регулярным выражением «приветствия». Ссылка `python.org` доходит до экрана.
7. Результаты теста и запуск примера не копятся в `Output`.
8. Часы компьютера снимаются в начале этапа и попадают в учебный промпт.
9. Пуш на GitHub — `bash .secrets/github_ssh/push_origin.sh`.

## Принятые решения

| Решение | Почему |
|---------|--------|
| Педагогические развилки — запрос к модели, без примера конкретного вопроса в коде | Заплатка под один вопрос ломается на следующем |
| Понятия урока готовятся при открытии урока, в профиль — при зачёте | Иначе ученик, который не нажал кнопку, «ничего не знает» |
| Примеры через уже запущенный клиент модели | Новый клиент на каждый клик брал чужой ключ и давал 401 |
| Пароль прокси вычищен из текущего файла | Услуга прокси уже истекла; в истории коммита `55b8437` строка ещё есть |

## Не делали

| | Почему |
|---|--------|
| Поиск актуальной версии на python.org из промпта | Текст промпта сеть не открывает. Нужен отдельный HTTP-запрос кода |
| Переписывание истории Git из-за пароля прокси | Прокси мёртвый, пароль кабинета отдельно. Force push не просили |
| Коммит укороченного титула `TeachAI.ipynb` | Это не согласованное название продукта |
