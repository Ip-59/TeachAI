## Цель сессии и итог

Разобрать, почему урок «Настройка IDE» уехал в списки и словари, и убрать из генерации механические подсказки темы. Дальше — честный вывод, если по уроку нет запускаемого кода, и починка обрезки ответа на вопрос.

**Итог:**

1. Правило «сохрани чат»: на флешку копируется локальный jsonl как есть, блок `**User**` только из `<user_query>`.
2. Из промпта урока убрана проверка слов `python` / `список` / `словарь` и дописка `append/insert/remove`.
3. Из промптов примеров и КЗ убраны готовые сюжеты (iris, возраст, «Анна», append/remove).
4. Если по уроку нет кода для редактора, ученик видит справку, не «Ошибка при генерации».
5. Вопрос на уроке оценивается как вопрос преподавателю этого урока, не как сверка фразы с текстом.
6. Регулярное выражение «приветствий» больше не съедает первое предложение и ссылку `python.org`.
7. В начале этапа снимаются локальные дата и время (`datetime.now().astimezone()`), строка попадает в учебный промпт.
8. Поиск актуальной версии в интернете промптом не включается: вызов модели — обычный chat completion без инструмента «открыть сайт».

## Принятые решения

| Решение | Почему |
|---------|--------|
| Один промпт урока без ветки по словам в названии курса | Ветка срабатывала на любом уроке «Основ Python» и тащила списки |
| Нет двушагового «сначала придумай промпт» | Лишний вызов и второй шанс уехать в сторону |
| Нет кода по теме → сообщение, не исключение | Шаги установки в поле `code` — не сбой генератора |
| Часы с компьютера в начале этапа и в промпте | «Сейчас» нельзя брать из отладочного файла |
| Актуальный номер версии модель сама с сайта не берёт | В запросе нет поиска. Факт должен добыть код TeachAI |

## Отклонённые
