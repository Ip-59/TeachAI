## 2. Принятые решения

1. **Не перечитывать репозиторий как в первый раз.** База — `doc/Описание_…` и `doc/Бриф_…` мая 2026 (v1.2), плюс дельта сентября.
2. **Слайды 11–12 — эксперимент моделей** (методика; таблица + вердикт). Майское «удалить слайд 11» отменено: тогда не было журнала промптов; теперь есть сравнение LLM. Это не таблица версий промптов.
3. **Запрет 95/90/85** сохранён (выдумка старых черновиков ИИ). Цифры бенчмарка другие: балл 0–10, ₽, latency, балл/₽.
4. **Внешняя «нейросеть для презентаций»** — не основной исполнитель. Ей только описание + бриф + шаблон. Сборку pptx лучше держать в этом проекте.
5. **17 слайдов по шаблону УИИ**, не урезать главы шаблона без отдельного согласования. Методичка этапа 6 короче (рекомендации); шаблон длиннее — держим шаблон.
6. **Вердикт на слайдах:** базовая модель `gpt-4o-mini` (лучший балл/₽ 14.72, ~12 с); апгрейд `gpt-5.6-luna` (8.40, ~0.88 ₽/урок). Terra / Claude Sonnet 5 / Gemini Flash для массовых уроков не берём.
7. **Роль агента** зафиксирована в `.cursor/rules/expert-role.mdc` (alwaysApply), отдельно от `critical-partner.mdc`.

## 4. Требования этапа 6 (факты из MarkText)

Файл: `doc/Этапы итогового проекта AI_ML (MarkText).md` (дублируется в `doc/!Инструкция. Дипломный проект AI_ML.pdf`).

- Регламент **≤ 20 мин**, свободная форма + визуал.
- Рекомендуемые блоки: титул (название, ФИО, **старт обучения**, дата защиты); постановка задачи; обучающая база **при наличии**; проектирование архитектур НС (можно несколько слайдов); финальная настройка НС (можно несколько).
- Дополнять можно; вычёркивать главы шаблона — только с автором.
- Избегать простыней текста, больших кусков кода, выступления на фоне открытого ноутбука.
- Этап 7 (интервью) в том же файле: **10–17 мин** — на защите бриф 17 слайдов может быть тесным; резать скорее 13–15, не эксперимент.

Адаптация TeachAI: слайд «база» → **«Данные и модель»**; гипотезы НС → сравнение готовых LLM; финальная настройка → вердикт mini / Luna.
