3. cSpell И РУССКИЙ ЯЗЫК
================================================================================

Пользователь:
почему так много сообщений об ошибка со стороны cSpell?

Ассистент:
cSpell проверяет орфографию, а не логику кода. Много ложных срабатываний из-за русского текста и техтерминов.

Решение:
- Включить русский: "cSpell.language": "en,ru"
- При необходимости установить Code Spell Checker: Russian
- Добавить проектные слова в "cSpell.words"

Пользователь:
как включить русский язык в cSpell

Ассистент:
Добавить в .vscode/settings.json:

{
  "cSpell.enabled": true,
  "cSpell.language": "en,ru"
}

Ассистент предоставил код:

----- Диаграмма 1: Архитектура (graph TD) -----

```mermaid
graph TD
    U[Пользователь в Jupyter Notebook] --> NB[TeachAI.ipynb]
    NB --> E[TeachAIEngine<br/>engine.py]

    E --> C[ConfigManager<br/>config.py]
    E --> S[StateManager<br/>state_manager.py]
    E --> L[Logger<br/>logger.py]
    E --> UI[UserInterface<br/>interface.py]
    E --> SD[StartupDashboard<br/>startup_dashboard.py]
    E --> A[Assessment<br/>assessment.py]
    E --> CG[ContentGenerator (Facade)<br/>content_generator.py]

    S --> UPM[UserProfileManager]
    S --> LPM[LearningProgressManager]
    S --> CDM[CourseDataManager]
    S --> STATE[(data/state.json)]

    UI --> SI[setup_interface.py]
    UI --> LI[lesson_interface.py]
    UI --> AI[assessment_interface.py]
    UI --> CI[completion_interface.py]

    CG --> CPG[CoursePlanGenerator]
    CG --> LG[LessonGenerator]
    CG --> EG[ExamplesGenerator]
    CG --> AG[AssessmentGenerator]
    CG --> QAG[QAGenerator]
    CG --> COG[ConceptsGenerator]
    CG --> RC[RelevanceChecker]

    CPG --> OAI[OpenAI API]
    LG --> OAI
    EG --> OAI
    AG --> OAI
    QAG --> OAI
    COG --> OAI
    RC --> OAI

    A --> CG
    LI --> CG
    AI --> A
    E --> STATE
```

----- Диаграмма 2: Sequence (главный юзкейс) -----

```mermaid
sequenceDiagram
    autonumber
    participant User as Пользователь
    participant NB as TeachAI.ipynb
    participant Engine as TeachAIEngine
    participant Config as ConfigManager
    participant State as StateManager
    participant UI as UserInterface
    participant CG as ContentGenerator
    participant OpenAI as OpenAI API
    participant Assess as Assessment

    User->>NB: Запускает ячейку с TeachAI
    NB->>Engine: start()

    Engine->>Config: load_config(), get_api_key()
    Config-->>Engine: OK / API key
    Engine->>State: load_state(), is_first_run()

    alt Первый запуск
        Engine->>UI: show_initial_setup()
        UI-->>User: Форма (тема, стиль, время)
        User->>UI: Подтверждает параметры
        UI->>CG: generate_course_plan(course_data,...)
        CG->>OpenAI: Запрос на генерацию плана курса
        OpenAI-->>CG: JSON-план курса
        CG-->>UI: Готовый план
        UI->>State: save_course_plan(), save_user_profile()
    else Повторный запуск
        Engine-->>User: Показывает StartupDashboard
        User->>Engine: Нажимает "Продолжить обучение"
    end

    Engine->>State: get_next_lesson()/current lesson
    Engine->>UI: show_lesson(section, topic, lesson)

    UI->>CG: generate_lesson(...)
    CG->>OpenAI: Запрос на генерацию урока
    OpenAI-->>CG: Контент урока
    CG-->>UI: Урок + форматированный вывод
    UI-->>User: Отображает материал

    User->>UI: Нажимает "Пройти тест"
    UI->>CG: generate_assessment(...)
    CG->>OpenAI: Генерация теста
    OpenAI-->>CG: Вопросы теста
    CG-->>UI: Список вопросов

    User->>UI: Отправляет ответы
    UI->>Assess: calculate_score(questions, answers)
    Assess-->>UI: score, feedback
    UI->>State: save_lesson_assessment(), update_progress()
    UI-->>User: Результат + переход к следующему уроку
```
