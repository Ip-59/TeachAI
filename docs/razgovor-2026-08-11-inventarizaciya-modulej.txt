Провёл статический анализ импортов от точки входа engine → TeachAI.ipynb /
run_teachai.py. Ниже инвентаризация и предложения по удалению — ничего не

=== Точки входа (актуальные) ===

| Файл            | Роль                                              |
|-----------------|---------------------------------------------------|
| TeachAI.ipynb   | Основной запуск: start_jupyter()                  |
| run_teachai.py  | Единая точка входа + reload для разработки        |
| engine.py       | Ядро: конфиг, состояние, генерация, UI            |

main.py дублировал запуск через TeachAIEngine, но нигде не импортировался;
в README ещё был указан прямой импорт engine.

=== Рабочее ядро (48 модулей, достижимы от engine) ===

Граф (упрощённо):

  TeachAI.ipynb → run_teachai.py → engine.py
                                      ├─ state_manager
                                      ├─ content_generator → генераторы
                                      └─ interface.py → lesson_interface
                                           → lesson_display / lesson_navigation
                                           → cell_integration → interactive_cell_*

Генерация контента:
  content_utils, content_renderer, content_formatter_final,
  course_plan_generator, lesson_generator,
  examples_generator (+ examples_generation, examples_validation,
  examples_display, examples_html_utils, examples_code_fixes),
  explanation_generator, assessment_generator, qa_generator,
  concepts_generator, relevance_checker.

Состояние:
  config, state_manager, user_profile_manager,
  learning_progress_manager, course_data_manager, logger.

Интерфейс:
  interface, interface_utils, setup_interface, lesson_interface,
  lesson_display, lesson_navigation, lesson_interaction, lesson_utils,
  assessment_interface, assessment_results_handler, control_tasks_interface,
  completion_interface, startup_dashboard, loading_indicators.

Интерактивные ячейки:
  cell_integration → interactive_cell_widget → cell_widget_base,
  interactive_cell_ui, interactive_cell_logic, result_checker,
  control_tasks_logger, control_tasks_generator, code_formatter.

Данные:
  courses.json (единственный JSON в git).
