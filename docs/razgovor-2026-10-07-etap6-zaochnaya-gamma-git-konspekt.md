## Принятые решения

1. **«Рубрику» на слайдах пока не переписывать.** Слово из бенчмарка: пять критериев по 0–2, сумма 0–10.
2. **Заочную версию генерировать в Gamma по отдельному промпту**, не скриптом `build_prezentaciya_zaochnaya.py`. Схемы рисовать здесь и вставлять готовыми PNG.
3. **Слайд «как читать» не начинает с 95/90/85 и не с порога 40%.** Эти пояснения стоят там, где читатель уже видит эксперимент и тест.
4. **40% — зачёт теста, не единственное условие перехода.** Урок закрыт, когда тест больше 40% и контрольное принято. 80% на скрине — балл одной попытки.
5. **Размер картинок в файле Gamma пока не править.** Автор с оценкой «картинки узкие» не согласился.
6. **Ядро ноутбука на этом компьютере — `venv_W_L`.** `venv_H_L` — домашний компьютер. В метаданных не подменять.
7. **`doc/` и `docs/` в GitHub не класть.** Презентации, которые должны отслеживаться, лежат в корне репозитория.
