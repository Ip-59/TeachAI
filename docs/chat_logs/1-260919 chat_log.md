## Напоминание: как мы сохраняли chat-логи раньше

1. **Куда:** `docs/chat_logs/`
2. **Имя файла:** `N-YYMMDD chat_log.md`
   - `N` — номер чата за этот календарный день (`1-`, `2-`, …)
   - `YYMMDD` — дата (`250825` = 25.08.2025; этот файл: `260919`)
3. **Содержимое:** по сути выгрузка диалога:
   - заголовок темы;
   - строка `_Exported on … from Cursor_`;
   - блоки `**User**` / `**Cursor**` через `---`;
   - важные куски кода и решений внутри ответов агента.
4. **Зачем:** флешка уезжает на другой ПК → чат в UI Cursor не едет → лог в проекте остаётся → в новом чате можно `@docs/chat_logs/…` или вставить бриф.
5. **Рядом по смыслу:** более «сжатые» разборы иногда клали в `docs/razgovor-….md` / `.txt` (не вместо chat_log, а как конспект).

Раньше лог часто получали через **Export** чата в Cursor и сохраняли под таким именем; если Export недоступен — агент реконструирует лог по сессии (как сейчас).
