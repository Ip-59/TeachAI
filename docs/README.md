# Документация проекта TeachAI

## Структура папок

### 📁 chat_logs/
Содержит все логи чат-сессий разработки:
- `N-YYMMDD chat_log.md` — диалог сессии (`1-260919 chat_log.md` …)
- Рядом в `docs/` — конспекты `razgovor-…-konspekt.md` (решения, пути, бриф)

**Постоянное правило агента:** в конце содержательного чата создавать chat-log + конспект  
(см. `.cursor/rules/chat-history.mdc`). Критический разбор запросов — `.cursor/rules/critical-partner.mdc`.

### 📁 project_docs/
Основная документация проекта:
- `PROJECT_STATUS.md` - текущий статус проекта
- `WORK_SESSION_LOG.md` - лог рабочих сессий
- `UX_IMPROVEMENT_PLAN.md` - план улучшения интерфейса
- `user-guide.md` - руководство пользователя
- `readme.md` - основное описание проекта
