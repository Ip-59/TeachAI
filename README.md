# TeachAI — интеллектуальная система персонализированного обучения Python и AI/ML на основе языковой модели

Интерактивный учитель в **Jupyter Notebook**: план, уроки, ответы на вопросы, тесты и практические задания генерирует готовая языковая модель по API. Свою модель система не дообучает и внешнюю базу данных не использует: состояние и кэш уроков — в `data/state.json`, журналы — в `logs/`.

Каталог курсов — Python, анализ данных и машинное обучение. Свой курс с произвольным названием модель сначала относит к этой области или нет. Тема вне области не стартует сама: можно выбрать другой курс или начать её после предупреждения. Если проверку выполнить не удалось, курс не запускается. Принудительный старт темы вне области сопровождается предупреждением о качестве материала и практики. Классификация темы и вопросов — решение модели; его точность этим репозиторием не измерена.

## Назначение

TeachAI ведёт обучение по курсу из каталога или по своему названию: генерирует текст уроков, отвечает на вопросы, предлагает примеры и объяснения, проводит тесты и контрольные задания с проверкой кода.

Вопрос на уроке модель относит к одному из трёх уровней (`relevance_checker.py`):

- `lesson` — материал этого урока, обычный ответ;
- `course` — предмет курса (язык, библиотеки, инструменты курса), но не этот урок: ответ есть, плюс пометка, что это не тема урока;
- `outside` — вопрос не про предмет курса: отказ, без ответа по существу.

Название и описание курса передаются отдельно от текста урока. Шапка «курс / раздел / тема» из текста урока снимается; название темы за название курса не подставляется. Поле `reason` — пояснение ученику. Слова в нём уровень не меняют. Узнаваемый `scope` важнее противоречащего `is_relevant`.

Некорректный ответ классификатора идёт двумя разными путями.

- Текст, из которого не достаётся JSON (`parse_llm_json`), уровнем не становится. `check_question_relevance` заканчивается ошибкой «Не удалось проверить релевантность вопроса». Кнопка вопроса показывает «Ошибка при генерации ответа» и ответ по теме не строит. Счётчики вопросов при этом не увеличиваются.
- JSON, который разобрался, но устроен не так (`_extract_relevance_from_response`), к одному решению не сводится. Объект без узнаваемого `scope` смотрит на `is_relevant`: поля нет или оно не читается как истина — уровень `outside` и отказ; истина — `lesson`. Разобранное значение без полей объекта (список, число, `null`) попадает в запасную ветку исключения: `scope=lesson`, вопрос принимается как материал урока. Форма ответа сама принимает вопрос только в этой ветке.

Тесты с подменой ответа модели проверяют разбор этого контракта, не точность живой модели.

Примеры, интерактивные ячейки и контрольные запускает дочерний процесс Python (`code_sandbox.py`): `stdin` закрыт, каталог временный, в окружение попадает ограниченный набор переменных. В интерфейс возвращаются вывод и сериализуемые результаты.

## Быстрый старт

### Требования

- Python 3 и пакеты из `requirements.txt` (интерфейс на Jupyter / ipywidgets) в том окружении, которым пользуются.
- Файл `.env` с ключом выбранного маршрута. Прокси нужен только для маршрута `proxy`.

Локальные окружения `venv_H_L` и `venv_W_L` — примеры уже существующих сред дома и на работе, не обязательная установка.

### Установка

```bash
pip install -r requirements.txt
test -f .env || cp .env.sample .env
```

`.env.sample` уже лежит в корне. Копируйте его в `.env` только если своего `.env` ещё нет: команда выше так и делает и не перезаписывает уже записанные настройки и ключи. В новом файле подставьте свои ключи. `OPENAI_API_ROUTE` в образце — пример заполнения, не значение по умолчанию в коде. Если ни один источник маршрута не задан, код выбирает `direct`.

### Запуск

Рекомендуемый способ — notebook `TeachAI.ipynb`. Сначала выполните ячейку настройки, затем ячейку Start. Это технический выбор до запуска. Учебный дашборд маршрут не показывает и не переключает.

```python
API_ROUTE = None  # либо "direct", "gptunnel" или "proxy"

from run_teachai import start_jupyter
start_jupyter(api_route=API_ROUTE)
```

`None` маршрут сам не назначает. `start_jupyter` сначала сбрасывает явный выбор прошлого запуска, затем загружает `.env` с перезаписью переменных процесса. Дальше (`llm_route.py`):

1. Непустой `OPENAI_API_ROUTE`. В ячейке допустимы только `direct`, `gptunnel` и `proxy`; та же тройка — основные значения этой переменной.
2. Если переменной нет — файл `data/llm_route_preference.json`.
3. Если файла нет — старые `OPENAI_USE_PROXY` и `OPENAI_CONNECTION_MODE`.
4. Иначе `direct`.

Непустое, но нераспознанное `OPENAI_API_ROUTE` файл preference не читает: дальше смотрятся старые переменные, иначе `direct`.

Строка `direct`, `gptunnel` или `proxy` в `API_ROUTE` ставится после загрузки `.env` и побеждает пункты выше. В `.env` и в файл preference она не пишется. Другое написание ячейка не принимает. `gptunnel` значением по умолчанию не является.

| Маршрут | Что нужно |
|---------|-----------|
| `direct` | `OPENAI_API_KEY`. Прокси приложения не используется. Доступность API зависит от сети машины и здесь не гарантируется. |
| `gptunnel` | `GPTUNNEL_API_KEY`. Базовый URL — `GPTUNNEL_BASE_URL`, иначе `https://gptunnel.ru/v1`. |
| `proxy` | `OPENAI_API_KEY` и URL в `OPENAI_PROXY`, иначе `HTTPS_PROXY` или `HTTP_PROXY` (те же имена допускаются в нижнем регистре). |

**Альтернатива** — CLI, без аргумента `api_route`. Действует та же цепочка, что при `API_ROUTE = None`:

```bash
python run_teachai.py
```

Точка входа: `run_teachai.py` → `TeachAIEngine` (`engine.py`). Если прогресс уже есть, сначала дашборд; клиент и генераторы поднимаются по «Продолжить обучение». При первом запуске инициализация идёт до экрана профиля.

## Каталог курсов

Пять курсов заданы в `courses.json`:

| ID | Название |
|----|----------|
| `python-basics` | Основы Python |
| `data-analysis` | Анализ данных с Python |
| `machine-learning` | Введение в машинное обучение |
| `web-development` | Веб-разработка на Python |
| `python-for-finance` | Python для финансов |

Библиотеки курса в `requirements.txt` (pandas, scikit-learn, TensorFlow, Flask, yfinance и др.) нужны, чтобы выполнять сгенерированные примеры и контрольные. Ядро системы на них не держится.

Свой курс в `courses.json` не записывается. Перед стартом модель оценивает, относится ли название к Python и AI/ML (`course_domain.py`).

## Архитектура (кратко)

```
TeachAI.ipynb / run_teachai.py
        │
        ▼
  TeachAIEngine (engine.py)
        │
        ├── ConfigManager (.env, директории logs/, data/)
        ├── StateManager (data/state.json)
        ├── ContentGenerator → специализированные генераторы (OpenAI)
        ├── Assessment (тесты)
        ├── Logger (logs/*.json, lesson_history.md)
        ├── StartupDashboard (повторный запуск)
        └── UserInterface (фасад)
                ├── SetupInterface
                ├── LessonInterface → Display / Navigation / Interaction
                ├── AssessmentInterface
                └── CompletionInterface
```

Маршрут LLM — `llm_route.py`. Проверка вопроса — `relevance_checker.py` внутри `ContentGenerator`. Код ученика — `code_sandbox.py`.

Подробные диаграммы и сценарии — в [ОПИСАНИЕ_ПРОЕКТА_TEACHAI.md](doc/ОПИСАНИЕ_ПРОЕКТА_TEACHAI.md).

## Завершение урока (факты из кода)

Урок считается **завершённым** (`learning_progress_manager.py`, `is_lesson_completed`), если:

1. он отмечен принудительно (`lesson_completion_status`), **или**
2. контрольное задание выполнено верно (`control_tasks`, поле `is_correct`) **и выполнено хотя бы одно условие:** тест **> 40%** или подтверждён переход к контрольному без теста (`control_task_bypass`).

Подтверждённый обход теста сам урок не завершает и контрольное не отменяет.

## Конфигурация

Имена переменных, без значений ключей:

| Переменная | Назначение |
|------------|------------|
| `OPENAI_API_KEY` | Ключ OpenAI для `direct` и `proxy` |
| `GPTUNNEL_API_KEY` | Ключ шлюза для `gptunnel` |
| `GPTUNNEL_BASE_URL` | Необязательный URL шлюза |
| `OPENAI_API_ROUTE` | `direct`, `gptunnel` или `proxy` в `.env`. Пустое значение маршрут не выбирает |
| `OPENAI_PROXY` / `HTTPS_PROXY` / `HTTP_PROXY` | URL прокси, только для маршрута `proxy` |
| `OPENAI_USE_PROXY` / `OPENAI_CONNECTION_MODE` | Старые переменные, если нет `OPENAI_API_ROUTE` и нет файла preference |
| `LLM_MODEL` | Модель чата. Если не задана — `gpt-4o-mini` (`llm_api_base.py`) |
| `VALIDATION_MODEL` | Модель проверки контрольных. Если не задана — берётся `LLM_MODEL`, иначе `gpt-4o-mini` (`control_tasks_generator.py`) |

## Проверка

Обычный прогон в уже выбранном окружении текущей машины:

```bash
python -m pytest -q
```

`pytest.ini` добавляет `-m "not live"`: тесты с маркером `live` по умолчанию не запускаются. Подмена ответа модели в тестах проверяет обработку данных, не точность живой классификации.

Перед полным прогоном остановите TeachAI и его ядро. Фикстура `real_data_untouched` в `tests/conftest.py` сверяет время и размер `data/state.json`: параллельное обучение может записать файл во время прогона. Повторный запуск ячейки Start — не остановка.
