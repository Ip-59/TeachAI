# TeachAI — Настройка виртуального окружения

_Экспортировано из сессии Cursor (1.1.6)_

---

## 🚀 Цель
Настроить виртуальное окружение для проекта **TeachAI** и корректно установить все зависимости.

---

## ⚙️ Почему команда `python` не сработала

- В Windows чаще всего используется **Python Launcher** — команда `py`.
- Команда `python` может отсутствовать в PATH или быть некорректной.

### 🛠 Решение
Всегда используйте `py` вместо `python` в PowerShell:

```powershell
# ✅ Правильно
py -m venv venv

# ❌ Неправильно
python -m venv venv
```

---

## 📝 Пошаговая инструкция по настройке

### 1️⃣ Создание виртуального окружения

```powershell
py -m venv venv
```

### 2️⃣ Активация виртуального окружения

```powershell
.env\Scripts\Activate.ps1
```

После активации вы увидите `(venv)` в начале строки терминала.

### 3️⃣ Обновление менеджеров пакетов

```powershell
py -m pip install --upgrade pip setuptools wheel
```

### 4️⃣ Установка зависимостей проекта

```powershell
py -m pip install -r requirements.txt
```

Если возникает ошибка из-за занятых файлов (например, `pywin32` или `notebook`), это может быть связано с:

- антивирусом,
- процессами Windows,
- блокированием временных файлов.

---

## 🔄 Что делать при ошибках установки

### ✅ Перезагрузка решает
Перезагрузите компьютер. Это освободит занятые файлы и очистит кэш процессов.

После перезагрузки повторите:

```powershell
.env\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

### 🚑 Установка без кэша
Если ошибка сохраняется, используйте:

```powershell
py -m pip install --no-cache-dir -r requirements.txt
```
