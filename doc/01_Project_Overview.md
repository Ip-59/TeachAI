# TeachAI — Обзор проекта

## 1. Что представляет собой проект

**TeachAI** — это интерактивная образовательная платформа на базе искусственного интеллекта, работающая в среде Jupyter Notebook. Система использует API OpenAI (GPT-3.5/4) для автоматической генерации персонализированного учебного контента: планов курсов, уроков, тестов, практических заданий, примеров и объяснений — всё на русском языке.

Проект представляет собой полноценную LMS (Learning Management System), где роль преподавателя выполняет языковая модель, а управление учебным процессом осуществляется модульной Python-системой.

## 2. Цели проекта

| # | Цель | Описание |
|---|------|----------|
| 1 | **Персонализированное обучение** | Адаптация контента под стиль общения, имя и уровень пользователя |
| 2 | **Автоматическая генерация контента** | Полный цикл создания учебных материалов через LLM без ручного написания |

| 5 | **Модульная архитектура** | Легкость расширения и поддержки через паттерн Facade и декомпозицию |

## 3. Задачи, решаемые системой

### 3.1 Управление курсами
- Хранение каталога курсов (`courses.json`) с метаданными (сложность, ключевые слова, пререквизиты)
- Генерация структурированных планов курсов через LLM (разделы → темы → уроки)
- Навигация по учебному плану с переходами между уроками

### 3.2 Генерация учебного контента
- **Уроки** — HTML-контент с теорией и примерами кода, адаптированный под стиль пользователя
- **Тесты** — 5 вопросов с вариантами ответов, генерируемые по содержанию урока
- **Контрольные задания** — практические задачи с эталонным решением и валидацией кода
- **Примеры** — дополнительные примеры кода по теме урока
- **Объяснения** — расширенные пояснения материала

### 3.3 Оценка знаний
- Тестирование с автоматической проверкой ответов
- Контрольные задания с выполнением кода в изолированной среде
- Двухступенчатая система завершения урока: пройден тест + выполнено контрольное задание
- Статистика: средний балл, количество пройденных тестов, процент прогресса

### 3.4 Интерактивное взаимодействие
- Задавание вопросов ИИ-преподавателю в контексте текущего урока
- Запрос дополнительных примеров и объяснений
- Дашборд с визуализацией прогресса обучения

## 4. Способы решения

### 4.1 Архитектурный подход
Проект построен на **паттерне Facade** — каждый крупный компонент (контент, интерфейс, состояние) представлен фасадным классом, который делегирует работу специализированным модулям:

```
TeachAI.ipynb  →  TeachAIEngine  ─┬→  ConfigManager
                                  ├→  StateManager (facade)      → UserProfileManager
                                  │                              → LearningProgressManager
                                  │                              → CourseDataManager
                                  ├→  ContentGenerator (facade)   → CoursePlanGenerator
                                  │                              → LessonGenerator
                                  │                              → AssessmentGenerator
                                  │                              → ExamplesGenerator
                                  │                              → ExplanationGenerator
                                  │                              → QAGenerator
                                  │                              → ControlTasksGenerator
                                  ├→  UserInterface (facade)      → SetupInterface
                                  │                              → LessonInterface (facade)
                                  │                              │   → LessonDisplay
                                  │                              │   → LessonNavigation
                                  │                              │   → LessonInteraction
                                  │                              ├→  AssessmentInterface
                                  │                              │   → AssessmentResultsHandler
                                  │                              ├→  ControlTasksInterface
                                  │                              ├→  CompletionInterface
                                  │                              └→  StartupDashboard
                                  ├→  Assessment
                                  ├→  SystemLogger
                                  └→  LLMProvider
```

### 4.2 Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Среда выполнения | Jupyter Notebook / JupyterLab |
| Язык программирования | Python 3.x |
| LLM API | OpenAI API (GPT-3.5-turbo-16k), поддержка Azure и OpenRouter |
| UI-виджеты | `ipywidgets` (HTML, Button, VBox, HBox, Output, RadioButtons и др.) |
| HTTP-клиент | `httpx` (поддержка прокси) |
| Конфигурация | `python-dotenv`, файл `.env` |
| Персистенция | JSON-файлы (`data/state.json`) |
| Логирование | `logging` (стандартная библиотека Python) |

### 4.4 Жизненный цикл сессии обучения

1. **Инициализация** → `TeachAIEngine.__init__()` загружает конфигурацию, создаёт все компоненты
2. **Запуск** → `engine.start()` проверяет профиль пользователя и наличие курса
3. **Настройка** → Если новый пользователь: `SetupInterface` показывает форму настройки → выбор курса
4. **Генерация курса** → `CoursePlanGenerator` создаёт учебный план через LLM
5. **Дашборд** → `StartupDashboard` показывает прогресс обучения
6. **Урок** → `LessonDisplay` генерирует и отображает контент урока
7. **Тест** → `AssessmentInterface` проводит тестирование → `AssessmentResultsHandler` обрабатывает результаты
8. **Контрольное задание** → `ControlTasksInterface` показывает задание → `ControlTasksGenerator` валидирует решение
9. **Следующий урок** → Переход к следующему уроку или завершение курса
10. **Завершение** → `CompletionInterface` показывает сертификат и рекомендации

### 4.5 Конфигурация и окружение

Файл `.env` содержит критические настройки:

```env
OPENAI_API_KEY=sk-...          # API ключ для OpenAI
LLM_PROVIDER=openai            # Провайдер LLM (openai/azure/openrouter/local)
LLM_MODEL=gpt-3.5-turbo-16k   # Модель для генерации
OPENAI_PROXY=http://...        # Прокси для доступа к API
HTTPS_PROXY=http://...         # Альтернативный прокси
```

## 6. Ключевые особенности реализации

- **Кэширование уроков** — Сгенерированные уроки сохраняются в `state.json` для повторного использования между сессиями
- **Retry-механизм** — `BaseContentGenerator.make_api_request_with_retries()` обеспечивает повторные попытки при сбоях сети (до 3 попыток с экспоненциальной задержкой)
- **Прокси-поддержка** — Все запросы к API проходят через настраиваемый HTTP-прокси (`httpx`)
- **Индикаторы загрузки** — `LoadingManager` показывает анимированные индикаторы при ожидании ответов от API
- **Двухступенчатое завершение** — Урок считается пройденным только при: тест > 40% + контрольное задание выполнено
- **4 стиля общения** — formal, friendly, casual, brief — влияют на тон всего контента
- **Форматирование кода** — `ContentFormatterFinal` и `CodeFormatter` обеспечивают правильное отображение кода в HTML
- **Debug-режим** — Все ответы API сохраняются в `debug_responses/` для отладки
