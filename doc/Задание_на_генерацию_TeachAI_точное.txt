# ЗАДАНИЕ ДЛЯ CHATGPT
Сгенерируй проект TeachAI, состоящий из двух файлов: engine.py и TeachAI.ipynb, обеспечивающих интерактивное обучение студента по учебному плану.

## Файл 1: engine.py
Реализуй класс `TeachAIEngine`, включающий:

### 1. Инициализация:
- Загружай ключ OpenAI из .env: `OPENAI_API_KEY`
- Инициализируй клиента OpenAI
- Создавай и используй файлы: `state.json`, `lesson_history.md`, `debug_openai_responses.log`

### 2. Методы:

#### 2.1 initialize_user()
Показывает форму с ipywidgets:
- Имя студента
- Уровень (Начальный, Средний, Продвинутый)
- Формат общения (Простой, Нейтральный, Официальный)
- Длительность курса (целое число часов)
- Длительность одного занятия

#### 2.2 generate_personal_plan()
Генерирует учебный план через OpenAI:
- В формате JSON:
{
  "Учебный_план": [
    {
      "Тема": "Название темы",
      "Подтемы": [
        {
          "Подтема": "Название подтемы",
          "Текст_занятия": "Полный текст занятия"
        }
      ]
    }
  ]
}
- Учитывай длительность курса и занятия.

#### 2.3 start_interface()
- Загружает `state.json`
- Если пользователь не инициализирован — вызывает `initialize_user()`
- Иначе — `lesson_interface()`

#### 2.4 lesson_interface()
- Показывает текущую тему, подтему, текст
- Добавляет кнопки:
  - **Продолжить**
  - **Объяснить подробнее**
  - **Привести пример**
  - **Закончить урок**
- При нажатии генерирует ответ через OpenAI
- Для отображения ответа использует `Markdown(...)` с `replace('```', '')`
- Показывает `spinner` (Label с текстом типа "⏳ подождите...")
- После кнопки "Закончить урок":
  - Показывает краткое резюме
  - Отображает: `Урок завершён. До новых встреч!`
  - Не вызывает os.kill, не завершает ядро

#### 2.5 generate_prompted_reply(base_text, mode)
- При mode="explain", "example" или "summary" генерирует объяснение, пример или резюме

#### 2.6 next_lesson_step()
- Переключает state на следующую подтему
- Сохраняет состояние в `state.json`

### 3. Визуальные улучшения:
- Используй стиль кнопок:
  style={'button_color': '#cce6ff'},
  layout=widgets.Layout(font_weight='bold', border='1px solid black')

- spinner = widgets.Label(value="")

## Файл 2: TeachAI.ipynb
- Импортирует класс из engine.py
- Создаёт объект и запускает интерфейс:
from engine import TeachAIEngine
teach_ai = TeachAIEngine()
teach_ai.start_interface()

## Важно:
- Удали все конструкции вида os.kill() или signal.SIGTERM
- Никогда не отображай Markdown с тройными кавычками ``` — очищай их .replace('```', '')
- План должен быть в правильном JSON-формате без обёртки и без кода (без ```json)
- По умолчанию используй модель "gpt-4o"
- Отображай ответы через display(Markdown(...))
- Кнопки должны быть легко заметны и визуально оформлены
