Скорректированное описание работы системы TeachAI
=================================================

Скорректированная схема работы системы:
-

---

#

# Этап 1: Первый запуск и инициализация

1. **Запуск Jupyter Notebook**
2. **Проверка модулей**
3. **Импорт модулей**
4. **Проверка конфигурации**
5. **Инициализация системы**

#

## Этап 2: Первоначальная настройка профиля и выбор курса

1. **Отображение формы настройки профиля**:

- Система предлагает ввести данные пользователя
- Форма содержит поля:
- Имя пользователя
- Общая продолжительность обучения (часов)
- Длительность одного занятия (минут)
- Предпочтительный стиль общения

2. **Загрузка списка курсов**:

- Система загружает список доступных курсов из файла courses.json
- Отображает список курсов для выбора сразу после заполнения профиля
- Пользователь выбирает курс и нажимает "Начать обучение"

3. **Генерация учебного плана**:

- Система формирует запрос к OpenAI для создания персонализированного учебного плана
- Запрос учитывает:
- Название и описание выбранного курса
- Указанное общее время обучения
- Длительность одного занятия
- API возвращает структурированный план с разделами, темами и уроками
- Для каждого элемента указывается:
- Название/заголовок
- Краткое описание
- Необходимое время изучения (в минутах)

4. **Сохранение профиля и плана**:

- Система сохраняет данные профиля и учебный план в state.json
- Выводит сообщение: "Ваш персонализированный учебный план готов!"
- Показывает общую структуру плана с расчетным временем прохождения

#

## Этап 3: Первый урок

1. **Загрузка первого урока**:

- Система определяет первый урок из учебного плана
- Формирует запрос к OpenAI для генерации контента урока с параметрами:
- Название и описание урока из плана
- Желаемая длительность изучения
- Стиль общения из профиля пользователя
- Рекомендации по объему и сложности материала

2. **Отображение урока**:

- Система отображает заголовок урока и сгенерированный контент
- Показывает ожидаемое время изучения и прогресс по курсу
- Отображает кнопки навигации:
- "Назад"
- "Задать вопрос"
- "Объясни подробнее"
- "Приведи примеры"
- "Пройти тест"

3. **Взаимодействие с уроком - новая опция**:

- При нажатии на "Приведи примеры":
- Система формирует запрос к OpenAI для генерации практических примеров
- Запрос включает содержание текущего урока и запрос на разнообразные примеры
- Сгенерированные примеры отображаются в отдельном блоке
- Предоставляется кнопка для закрытия блока примеров

#

## Этап 4: Прохождение теста

1. **Начало тестирования**
2. **Ответы на вопросы**
3. **Проверка результатов**
4. **Сохранение результатов**

#

## Этап 5: Переход ко второму уроку

1. **Запрос на переход**
2. **Генерация содержания второго урока через API**
3. **Отображение второго урока**
