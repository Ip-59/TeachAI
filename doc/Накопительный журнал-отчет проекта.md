## Сессия 1: Демонстрационные ячейки

#

## Ошибка 1: Относительные импорты

-

 **Проблема:** `ImportError: attempted relative import with no known parent package`

-

 **Причина:** Использование `from .module import` в отдельных файлах

-

 **Решение:** Заменил на абсолютные импорты `from module import`

-

 **Урок:** В Jupyter Notebook всегда использовать абсолютные импорты

#

## Ошибка 2: Некорректное выполнение рекурсивных функций

-

 **Проблема:** `NameError: name 'factorial' is not defined` в демонстрации факториала

-

 **Причина:** Разделение на `local_namespace` и `global_namespace` мешало вызову функций

-

 **Решение:** Убрал разделение пространств имен, используем единое `execution_namespace`

-

 **Урок:** Для корректной работы функций нужно единое пространство имен

#

## Ошибка 3: Проблемы с форматированием кода

-

 **Проблема:** Код отображался в одну строку без переносов

-

 **Причина:** Использование `<code>` вместо `<pre>`

-

 **Решение:** Переписал HTML-структуру с использованием `<pre>` для сохранения форматирования

-

 **Урок:** Для отображения многострочного кода использовать `<pre>`

#

## Ошибка 4: Невидимое эмодзи в заголовке

-

 **Проблема:** Эмодзи 📄 отображалось блекло или не видно

-

 **Причина:** Некоторые эмодзи плохо отображаются в разных системах

-

 **Решение:** Заменили на змею 🐍 (тематично для Python и хорошо видно)

-

 **Урок:** Проверять совместимость эмодзи в разных системах

#

## Ошибка 5: Избыточные отступы в интерфейсе

-

 **Проблема:** Слишком большие `margin` и `padding` делали интерфейс громоздким

-

 **Решение:** Уменьшили отступы с 10-15px до 5px, сделали интерфейс компактнее

-

 **Урок:** Обращать внимание на компактность интерфейса

## Сессия 2: Интерактивные ячейки

#

## Ошибка 6: Отсутствующий параметр в функции-помощнике

-

 **Проблема:** `TypeError: create_interactive_cell() got an unexpected keyword argument 'cell_id'`

-

 **Причина:** В функции `create_interactive_cell` забыл добавить параметр `cell_id`

-

 **Решение:** Добавил недостающий параметр в сигнатуру функции

-

 **Урок:** Всегда проверять соответствие параметров в функциях-помощниках

#

## Ошибка 7: Система не находит результат выполнения

-

 **Проблема:** Получен `None` вместо результата `42` при правильном коде `result = 15 + 27`

-

 **Причина:** Код заканчивается присваиванием, не возвращает значение автоматически

-

 **Решение:** Улучшил логику поиска переменных в `execution_namespace`

-

 **Урок:** Система должна искать результат в переменных, а не только в возвращаемых значениях

#

## Ошибка 8: Неправильное пространство имен выполнения

-

 **Проблема:** Переменные не сохранялись между выполнениями

-

 **Причина:** Использовал `globals().copy()` вместо персистентного пространства

-

 **Решение:** Создал `self.execution_namespace = {}` как атрибут экземпляра

-

 **Урок:** Для интерактивных ячеек нужно персистентное пространство имен

#

## Ошибка 9: Некорректная обработка None в проверке списков

-

 **Проблема:** `'NoneType' object is not iterable` при проверке списков

-

 **Причина:** `ListChecker` не обрабатывал случай `result is None`

-

 **Решение:** Добавил проверку на None с понятным сообщением студенту

-

 **Урок:** Все проверяющие классы должны обрабатывать None

#

## Ошибка 10: Ошибка форматирования в f-строке

-

 **Проблема:** `ValueError: Invalid format specifier '.1% if stats else 'N/A''`

-

 **Причина:** Условное выражение внутри спецификатора формата f-строки

-

 **Решение:** Вынес условие в отдельную переменную перед f-строкой

-

 **Урок:** В f-строках нельзя использовать условные выражения в спецификаторах формата

## 1. Система проверки результатов

```

python
```

python

-

 **Обоснование:** Модульность, расширяемость

## 2. Многоуровневый поиск результатов

-

 **Обоснование:** Студенты пишут код по-разному

-

 **Альтернатива:** Строгое требование возвращать результат определенным способом
