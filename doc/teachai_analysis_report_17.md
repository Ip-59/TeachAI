### 🔄 **ПРОБЛЕМЫ С ЗАКРЫТИЕМ ИНТЕРАКТИВНЫХ КОНТЕЙНЕРОВ**
**Симптомы**: Кнопки закрытия не работают, невозможно вернуться к основному интерфейсу

**Решение из этапа 17 (проблема #83)**:
```python
# НЕПРАВИЛЬНО - попытка скрыть контейнер изнутри
def on_close_clicked(b):
    self._hide_explanation_container()  # Не работает из-за контекста

# ПРАВИЛЬНО - полная перерисовка интерфейса
def on_close_clicked(b):
    clear_output(wait=True)
    lesson_widget = self.show_lesson(
        self.current_course_info["section_id"],
        self.current_course_info["topic_id"],
        self.current_course_info["lesson_id"]
    )
    display(lesson_widget)
```

**Принцип**: Вместо попытки манипулировать layout.display изнутри `with container:`, лучше полностью перерисовать интерфейс.

### 📝 **ПРОБЛЕМЫ С ГЕНЕРАЦИЕЙ КОНТЕНТА**
**Симптомы**: Неуместные элементы в сгенерированном контенте

**Решение из этапа 17 (проблема #84)**:
```python
# НЕПРАВИЛЬНО - общий промпт без ограничений
{"role": "system", "content": "Ты - опытный преподаватель..."}

# ПРАВИЛЬНО - четкие ограничения в промпте
{"role": "system", "content": "Ты - опытный преподаватель... БЕЗ финальных прощаний и пожеланий удачи."}

# И в самом промпте:
"- НЕ ЗАВЕРШАЙ урок прощанием, пожеланиями удачи или фразами типа 'до новых встреч'"
```

### 🎨 **ПРОБЛЕМЫ С ЧИТАЕМОСТЬЮ КОДА**
**Симптомы**: Черные блоки кода, нечитаемый текст

**Решение из этапа 17 (проблема #85)**:
```css
/* НЕПРАВИЛЬНО - контрастные нечитаемые стили */
.examples-compact code {
    background-color: #1a1a1a;
    color: #00ff41;  /* Зеленый на черном - нечитаемо */
}

/* ПРАВИЛЬНО - светлые читаемые стили */
.examples-visible code {
    background-color: #f8f9fa;
    color: #d63384;  /* Контрастный на светлом фоне */
    border: 1px solid #dee2e6;
}
```

### 🔄 **ПРОБЛЕМЫ С ЕДИНООБРАЗИЕМ ФОРМАТИРОВАНИЯ**
**Симптомы**: Разные стили для похожих элементов интерфейса

**Решение из этапа 17 (проблема #86)**:
```python
# НЕПРАВИЛЬНО - разные CSS классы
<div class="non-relevant-answer">  # Отдельный класс
<div class="qa-answer">            # Другой класс

# ПРАВИЛЬНО - один класс, разные цвета
<div class="qa-answer">  # Один класс для всех ответов
# Только background меняется:
# Релевантные: background: linear-gradient(135deg, #e7f3ff 0%, #cce7ff 100%);
# Нерелевантные: background: linear-gradient(135deg, #fff3cd 0%, #ffeaa7 100%);
```

## 🎯 ОБНОВЛЕННЫЕ МЕТОДОЛОГИЧЕСКИЕ ПРИНЦИПЫ

### ✅ ПРОВЕРЕННЫЕ ПРИНЦИПЫ УСПЕШНОЙ РАБОТЫ (дополнено):
1. **Изучение образцов**: использование working решений из других модулей
2. **Полная перерисовка вместо скрытия**: для сложных интерактивных элементов
3. **Читаемость превыше красоты**: светлые фоны для кода вместо темных
4. **Единообразие стилей**: один CSS класс для похожих элементов
5. **Четкие ограничения в промптах**: явные запреты на нежелательный контент
6. **Детальное логирование**: сохранение всех действий пользователя
7. **Поэтапная реализация**: завершение всех начатых функций

### ❌ ДОПОЛНЕННЫЙ СПИСОК АНТИПАТТЕРНОВ:
1. **Попытки скрытия контейнеров изнутри**: layout.display = "none" не работает в контексте
2. **Темные контрастные стили для кода**: черный фон делает код нечитаемым  
3. **Разные CSS классы для похожих элементов**: создает визуальную неконсистентность
4. **Неконтролируемый контент от AI**: отсутствие ограничений в промптах
5. **Игнорирование пользовательского опыта**: неработающие кнопки блокируют работу
6. **Недостаточное тестирование UX**: проблемы выявляются только при использовании
